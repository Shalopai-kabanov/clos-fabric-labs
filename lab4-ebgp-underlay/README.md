# Лабораторная работа №4 - eBGP Underlay

## Цель работы

Настроить eBGP в качестве Underlay-протокола в топологии Spine-Leaf для обеспечения IP связности между всеми сетевыми устройствами.

---

## План работы

1. Построить топологию Spine-Leaf.
2. Настроить L3 интерфейсы между устройствами.
3. Назначить IP адресацию.
4. Настроить eBGP соседства между Spine и Leaf устройствами.
5. Выполнить анонс маршрутов через BGP.
6. Проверить состояние BGP соседств.
7. Проверить установку маршрутов в таблицу маршрутизации.
8. Проверить IP связность между Loopback интерфейсами.

В таблице BGP присутствуют два равнозначных маршрута до удалённых Loopback интерфейсов, что подтверждает работу ECMP.

## Вывод

В ходе лабораторной работы был настроен eBGP Underlay в топологии Spine-Leaf.

Каждому устройству была назначена собственная автономная система. Между всеми соседними устройствами были установлены eBGP-сессии. Маршруты успешно распространяются между всеми коммутаторами фабрики.

Проверка таблиц маршрутизации показала наличие маршрутов ко всем Loopback интерфейсам. Для удалённых сетей используется ECMP через оба Spine-коммутатора, что обеспечивает балансировку нагрузки и отказоустойчивость.

Проверка ICMP показала полную IP связность между всеми устройствами в BGP домене.
